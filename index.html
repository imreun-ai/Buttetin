ការគណនា

និទ្ទេសគិតជាភាគរយនៃមធ្យមភាគពេញ ៖ A ≥ ៩០%, B ≥ ៨០%, C ≥ ៧០%, D ≥ ៦០%, E ≥ ៥០%, F < ៥០%។ ពិន្ទុវិជ្ជាសម្បទា = មធ្យមភាគប្រចាំឆ្នាំ × (ភាគរយ ÷ ១០០)។

មុខវិជ្ជា

ពិន្ទុសរុប = Σ (ពិន្ទុ × មេគុណ) · មធ្យមភាគ = ពិន្ទុសរុប ÷ Σមេគុណ។ ពេលជ្រើសកម្រិតថ្នាក់ មេគុណ = ពិន្ទុពេញ ÷ មធ្យមភាគពេញ (ឧ. ១០០ → ២, ១៥០ → ៣, ៧៥ → ១.៥) ហើយអាចកែដោយដៃបាន។

ពិន្ទុប្រឡងឆមាសទី២

ពិន្ទុប្រចាំឆ្នាំ (ឆមាសទី១ + ឆមាសទី២) ÷ ២ — គណនាស្វ័យប្រវត្តិ

បើមានពិន្ទុតែឆមាសមួយ ប្រព័ន្ធយកតម្លៃឆមាសនោះជាប្រចាំឆ្នាំបណ្តោះអាសន្ន។

ពិន្ទុបំណិន

ជំហានភ្ជាប់ជាមួយ Google Sheet

  1. បើក Google Sheet របស់អ្នក → Extensions → Apps Script។
  2. ចុច ចម្លងកូដ ខាងក្រោម បិទភ្ជាប់ជំនួសកូដចាស់ → Save។
  3. ជ្រើស function setup → Run (អនុញ្ញាតសិទ្ធិ) ដើម្បីបង្កើត Sheet ដែលត្រូវប្រើដោយស្វ័យប្រវត្តិ។
  4. Deploy → New deployment → Web app ៖ Execute as Me · Who has access Anyone → ចម្លង URL (ចុងបញ្ចប់ /exec)។
  5. បិទភ្ជាប់ URL ខាងក្រោម រួចចុចផ្ញើ ឬទាញយក។
